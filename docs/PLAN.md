# Plan de trabajo DevOps
## Historias de usuario
- HU01: Como usuario quiero registrar tareas con nombre, descripción y prioridad para organizar mi trabajo.
- HU02: Como usuario quiero consultar las tareas para conocer mis pendientes.
- HU03: Como usuario quiero editar tareas para corregir información.
- HU04: Como usuario quiero eliminar tareas que ya no necesito.
- HU05: Como usuario quiero cambiar estados entre Pendiente, En proceso y Terminada para conocer avances.
- HU06: Como usuario quiero asignar prioridad Alta, Media o Baja para ordenar el trabajo.

## GitHub Project
Crear tablero Board con Backlog, To Do, In Progress, Review y Done. Campos: responsable, prioridad, estimación, fase DevOps y fecha límite.

## Fases
Plan, Code, Build, Test, Release, Deploy, Operate, Monitor.

## Responsables
Asignar los integrantes reales del equipo antes de la entrega.
